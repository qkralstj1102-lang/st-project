## 왜 이 주제인가 (팀이 씁니다)
우리 팀원들의 진로인 항해사, 비행기 조종사, 컴퓨터공학은 모두 기계와 제어 시스템을 다룬다는 공통점이 있다. 이에 기계와 컴퓨터 기술이 결합된 산업용 로봇에 관심을 갖게 되었고, 산업용 로봇의 도입이 증가하면서 안전사고에는 어떤 변화가 나타났는지 궁금해져 이 주제를 선택하였다.
박민서: 뉴스를 보던중에 산업 로봇의 도입률이 높아지고 있다는것을 보고 그럼 산업 재해자수가 감소할것인가의 의문을 품고 주제를 선택함.
임주안: 인공지능 수학 수업중에 AI가 일자리를 대체한다는 다큐를 보고 그럼 로봇이 사람의 일을 대신할때 안전사고의 발생률이 감소하는지에 대한 의구심이 들어 주제를 선택했다.
장준명: SNS를 보던중에 AI가 일자리를 대체한다는 소식을 듣고 그럼 AI로봇이 일을 대체하면 사고도 줄어드는지 궁금하여 주제를 선택했다.
